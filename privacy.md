# Privacy Policy

_Last updated: October 28, 2026_

This policy covers every Google Cloud project and OAuth app published by
Aaron Brown ("the developer"), including `tli`.

## Who these apps are for

These apps are **private tools built for the developer's own personal use**.
They are not offered, marketed, sold or supported for use by anyone else. No
other person is invited or authorized to sign in to them.

## What data the apps access

When the developer signs in, an app may request access to Google account data,
such as Gmail messages and labels, only as needed for its single personal
purpose. For example, `tli` reads newsletter emails under specific Gmail labels
and updates those labels after processing.

## How the data is used and stored

- Data is used only to provide the app's function to the developer.
- Data is stored only on the developer's own computer and databases.
- Data is **not** sold, shared, transferred or disclosed to any third party.
- Data is **not** used for advertising, and is not used to train generalized
  AI or machine learning models.
- No humans other than the developer read the data.

## Google API Services User Data Policy

These apps' use and transfer to any other app of information received from
Google APIs will adhere to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Revoking access and deleting data

Access can be revoked at any time from
<https://myaccount.google.com/permissions>. Locally stored data can be deleted
by the developer at any time.

apps does so without authorization and **entirely at their own risk**. That
person is solely responsible for their own use, their own data, and any
consequences. The developer accepts no liability for it.
